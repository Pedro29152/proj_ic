# BTA

## Biblioteca de Trabalhos Acadêmicos Prof. Me. Silvio José Rosa

## Dependências

- python 3.6.6
- MySQL Server 8.0.16

## Instalação do ambiente

Digite os seguintes comandos:

- cd proj_ic
- pip install virtualenv
- pip install virtualenvwrapper-win
- mkvirtualenv -p python biblioteca-api
- workon biblioteca-api
- pip install -r ./requirements/base.txt

## Rodando a aplicação

Digite o comando abaixo:

- python application.py
