	Uma biblioteca virtual, por definição, é um local digital onde se arazenam dados em forma de livros ou imagens ou audios ou qualquer outro tipo de material de cunho intelectual, normalmente utilizados em empresas ou em instituicoes de estudo como, por exemplo, universidades ou bibliotecas para ambientes corporativos, onde os funcionarios necessitam de material para poderem efetuar suas tarefas de maneira mais facil. 
	No caso do sitema da Biblioteca de TGs a historia nao muda muito, pois o objetivo do sistema é de armazenar projetos antes feitos por estudantes da instituicao de ensino FATEC de Carapicuíba em um servidor da propria instituicao, que esta localizado na mesma, para que novos estudantes da instituicao possam ter facil acesso aos documentos, e assim, terem uma base para desenvolverem seus proprios projetos e terem uma base ded como faze algo bem feito.
	O sistema ira utilizar de duas ferramentas principas, que serao vue.js e flask. Vue que sera o responsavel pelo front-end, ou seja, a parte que o cliente interage, que ele vê e Flask sera a ferramenta de back-end que é a parte que fica alem do que os olhos podem ver, a parte responsavel pelo processasmento sobre o que o usuario esta fazendo no front end e sobre o que mandar de volta para o usuario.

	Vue é uma aplicacao para construcao de interfaces normalmente voltada para web, de uma maneira que a integracao com outras bibliotecas ou outros projetos é feita de uma maneira muito simples, o que acaba tornando o desenvolvimento com essa aplicacao muito simples e facil. Utiliza para o controle de suas views a linguagem JavaScript que esta diretamente ligada as tags da view, e essas tags podem possuir textos, classes, atributos, etc..
	Flask é um micro-framework web para Python de desenvolvimento de sistemas web completos, utilizando de outras duas bibliotecas que sao Werkzeug e Jinja2. Werkzeug é utilizado para se desenvolver apps WSGI(Web Server Gateway Interface)ou Interface de Porta de Entrade do Servidor Web, ou seja, é o responsavel por controlar tudo o que entra e tudo o que sai do servidor, incluido validacoes ou bloqueios de acesso e etc. E a biblioteca do jinja2 é um motor de templates, que utiliza de marcacoes em seus codigos para marcar lugares onde os valores devem ser substituidos no template, e esses valores sao valores que sao passados atravez do servidor para serem exibidos na tela de uma maneira responsiva, porem nao iremos utilizar deste motor pois ja temos um substituto para ele, o vue.js, que sera o responsavel pelos templates e tudo que envolver front-end.
